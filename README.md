# paper-method-diagram

把论文方法或项目说明整理成绘图大纲，再据此制作可编辑的论文方法图。适用于模型架构、算法流程、训练与推理、Agent 与检索、系统协议、实验流程和基准构建等场景。

## 在 Codex 中使用

1. 解压压缩包，将整个 `paper-method-diagram` 目录放到项目的 `.agents/skills/` 下。安装后的入口是 `.agents/skills/paper-method-diagram/SKILL.md`。
2. 准备论文 PDF、方法段、原图和图注。手头只有项目代码或研究构想时，先整理问题设定、主要步骤和关键规则。
3. 先让 Codex 输出 `绘图大纲.md`，核对模块的输入、操作、输出、分支和反馈，再把大纲交给 Skill 绘图。

## 可复制的提示词

先整理大纲：

> 根据我提供的论文方法、原图和图注，整理一份绘图大纲.md。写清每个模块的输入、操作、输出、连线和出处，并标出需要单独展开的关键机制。

再调用 Skill：

> 用 $paper-method-diagram 按这份绘图大纲.md 制作论文方法图。总图画清整体流程，局部图展开关键机制。交付原生可编辑 PPTX、矢量 SVG 和高清 PNG。

## 输出文件

| 格式 | 用途 |
|---|---|
| PPTX | 在 PowerPoint 或 WPS 中修改文字、形状和连线。引用的图片可作为对象移动或替换。 |
| SVG | 用于需要矢量图的排版场景。 |
| 高清 PNG | 用于预览和插入文档。 |

绘图和导出使用当前宿主提供的工具。生成 PPTX 后可直接用演示软件打开。

`examples/` 中有三张视觉参考图，分别用于参考机制展开、实验分支和关系变化。具体模块、箭头和素材以当前论文及绘图大纲为准。
